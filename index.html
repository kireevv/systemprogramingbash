Коротка інформація про GNU/Linux

GNU/Linux — сімейство вільних операційних систем з відкритим вихідним кодом, побудованих на базі ядра Linux, яке розробив Лінус Торвальдс у 1991 році, та системних утиліт проєкту GNU (ініційованого Річардом Столлманом у 1983 р.). Поширюється під ліцензією GPL — гарантує свободу використання, вивчення, зміни та поширення коду.

Команди Linux CLI

Натисніть на команду, щоб розгорнути опис та приклади використання.

pwdPrint Working Directory — вивести поточну директорію
▼

Виводить повний шлях до поточного робочого каталогу. Незамінна команда, щоб зорієнтуватись у файловій системі.

user@linux:~$ pwd /home/user user@linux:/var/log$ pwd /var/log
echoВивести текст або значення змінної на екран
▼

Виводить рядок тексту або значення змінної. Широко застосовується у скриптах і для запису у файли.

user@linux:~$ echo "Привіт, Linux!" Привіт, Linux! user@linux:~$ echo $HOME /home/user user@linux:~$ echo "Текст" > file.txt # запис у файл
lsList — показати вміст директорії
▼

Відображає список файлів і каталогів. Підтримує численні опції для різних форматів виведення.

user@linux:~$ ls Desktop Documents Downloads Music Pictures user@linux:~$ ls -la # детальний список + приховані файли total 48 drwxr-xr-x 8 user user 4096 Sep 26 12:00 . -rw-r--r-- 1 user user 220 Sep 25 10:00 .bash_logout user@linux:~$ ls -lh /var/log # читабельний розмір файлів
cdChange Directory — змінити поточну директорію
▼

Переміщає між каталогами файлової системи. Підтримує абсолютні та відносні шляхи.

user@linux:~$ cd /var/log user@linux:/var/log$ cd .. # на рівень вгору user@linux:/var$ cd ~ # до домашньої директорії user@linux:~$ cd - # до попередньої директорії /var
touchСтворити порожній файл або оновити час модифікації
▼

Створює новий порожній файл або оновлює часову мітку існуючого. Зручна для швидкого створення файлів у скриптах.

user@linux:~$ touch myfile.txt user@linux:~$ touch file1.txt file2.txt file3.txt user@linux:~$ ls -l myfile.txt -rw-r--r-- 1 user user 0 Sep 26 12:00 myfile.txt
mkdirMake Directory — створити нову директорію
▼

Створює одну або кілька директорій. З опцією -p формує весь ланцюжок вкладених каталогів.

user@linux:~$ mkdir myproject user@linux:~$ mkdir -p projects/web/css # вкладені каталоги user@linux:~$ mkdir dir1 dir2 dir3 # кілька одночасно user@linux:~$ ls dir1 dir2 dir3 myproject projects
cpCopy — копіювати файли та директорії
▼

Копіює файли та каталоги. Для рекурсивного копіювання директорій використовуйте прапорець -r.

user@linux:~$ cp file.txt backup.txt user@linux:~$ cp file.txt /home/user/Documents/ user@linux:~$ cp -r mydir/ /backup/mydir/ # директорія рекурсивно user@linux:~$ cp -v file.txt /tmp/ # verbose-режим 'file.txt' -> '/tmp/file.txt'
mvMove — переміщення або перейменування файлів
▼

Переміщує або перейменовує файли і каталоги. На відміну від cp, оригінал видаляється.

user@linux:~$ mv oldname.txt newname.txt # перейменування user@linux:~$ mv file.txt /tmp/ # переміщення user@linux:~$ mv *.txt Documents/ # перемістити всі .txt user@linux:~$ mv -i file.txt dest/ # з підтвердженням перезапису
rmRemove — видалити файли та директорії
▼

⚠️ Видаляє файли назавжди, без кошика! Особливо обережно із -rf!

user@linux:~$ rm file.txt user@linux:~$ rm -i file.txt # з підтвердженням rm: remove regular file 'file.txt'? y user@linux:~$ rm -r mydir/ # видалити директорію user@linux:~$ rm *.log # видалити всі .log файли
historyПоказати історію виконаних команд
▼

Виводить пронумерований список раніше введених команд. Можна повторювати команди за номером або шукати серед них.

user@linux:~$ history 1 pwd 2 ls -la 3 cd Documents 4 touch notes.txt 5 mkdir backup user@linux:~$ history 5 # показати останні 5 команд user@linux:~$ !3 # повторити команду №3 user@linux:~$ history | grep "ls" # пошук в історії

BASH-скрипт: Авторизація в системі

Скрипт імітує процес авторизації в текстовому режимі — перевіряє логін та пароль, обмежує кількість спроб (3 спроби) та виводить привітальне повідомлення після успішного входу.

📄 auth.sh
#!/bin/bash # ============================================================ # auth.sh — Скрипт авторизації в текстовому режимі # Демонстраційний BASH-скрипт для навчальних цілей # ============================================================ # --- Кольори ANSI для виводу в термінал --- RED='\033[0;31m' GREEN='\033[0;32m' YELLOW='\033[1;33m' CYAN='\033[0;36m' BOLD='\033[1m' NC='\033[0m' # No Color (скидання кольору) # --- Облікові дані користувача --- VALID_USER="admin" VALID_PASS="linux2024" MAX_ATTEMPTS=3 # --- Функція: виведення банера --- show_banner() { clear echo -e "${CYAN}${BOLD}" echo " ╔════════════════════════════════╗" echo " ║ GNU/Linux Authorization ║" echo " ║ Система авторизації ║" echo -e " ╚════════════════════════════════╝${NC}" echo "" } # --- Функція: перевірка облікових даних --- check_credentials() { local user="$1" local pass="$2" if [[ "$user" == "$VALID_USER" && "$pass" == "$VALID_PASS" ]]; then return 0 # успіх else return 1 # невдача fi } # --- Функція: привітальне повідомлення --- welcome_message() { local user="$1" DATE=$(date "+%d.%m.%Y %H:%M:%S") echo -e "${GREEN}" echo " ✓ Авторизацію успішно пройдено!" echo " ──────────────────────────────────" echo " Вітаємо, ${user}!" echo " Дата входу: ${DATE}" echo -e "${NC}" } # ============ ГОЛОВНИЙ БЛОК ПРОГРАМИ ============ main() { attempts=0 show_banner while [[ $attempts -lt $MAX_ATTEMPTS ]]; do remaining=$(( MAX_ATTEMPTS - attempts )) echo -e "${YELLOW} Спроб залишилось: ${remaining}${NC}" echo -n " Логін: " read -r username echo -n " Пароль: " read -rs password # -s приховує введення пароля echo ""; echo "" if check_credentials "$username" "$password"; then welcome_message "$username" exit 0 else (( attempts++ )) if [[ $attempts -lt $MAX_ATTEMPTS ]]; then echo -e "${RED} ✗ Невірний логін або пароль.${NC}" echo "" sleep 1 fi fi done echo -e "${RED}${BOLD} ✗ Перевищено максимальну кількість спроб." echo -e " Обліковий запис тимчасово заблоковано.${NC}" exit 1 } # Запуск головної функції main
🖥️ Інтерактивний симулятор Логін: admin  |  Пароль: linux2024
